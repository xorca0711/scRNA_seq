# Sources

`strunz_2020_supplementary_data_3.xlsx` is the unmodified
`41467_2020_17358_MOESM6_ESM.xlsx` member of the public Europe PMC
[PMC7366678 supplementary archive](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7366678/supplementaryFiles),
retrieved 2026-09-22. The original archive is cached under
`raw_data/literature/PMC7366678_supplementary.zip`.

Primary article: Strunz et al., *Alveolar regeneration through a Krt8+
transitional stem cell state that persists in human lung fibrosis*,
[Nature Communications 11, 3559 (2020)](https://doi.org/10.1038/s41467-020-17358-3).
The paper is CC BY 4.0. This file is reused with source attribution; no
endorsement is implied.

The workbook legend describes differential expression across alternative
cell groupings. ES1 uses `cell_types_2`, which distinguishes activated AT2
from AT2, and selects every row for the exact author labels `Krt8 ADI`,
`AT2 cells`, and `AT1 cells`. Each list contains 400 distinct genes. No gene
ranking or threshold is derived from ES1 data. Unmodified and label-free
lists are both stored in `../modules.json`, with source SHA-256 hashes.

The Choi and combined DATP/PATS definitions remain traceable to the existing
repository source extracts/scripts. They are short marker panels, not full
state signatures. The MSigDB files are complete cached 2024.1.Mm Hallmark
sets and are used as pathway controls, not as substitute DATP signatures.
